# Reglas de UI de Admin

- Usar primitivas de Polaris y evitar sistemas visuales custom para el admin embebido.
- Las etiquetas de navegación deben reflejar el lenguaje del dominio: Dashboard, Afiliados, Conversiones, Configuración.
- Las tablas deben usar formateo de dinero desde centavos para evitar desvíos de punto flotante en la UI.
