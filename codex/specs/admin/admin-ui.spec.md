# Spec de UI de Admin

## Páginas

- `/app`: dashboard
- `/app/affiliates`: registro de afiliados
- `/app/conversions`: log de conversiones
- `/app/settings`: valores por defecto de la instalación

## Reglas de UX

- La navegación embebida debe mantenerse plana y explícita.
- Los datasets vacíos deben renderizar copy útil.
