# Spec del Panel de Admin

## Objetivo

Proveer un dashboard para merchants dentro de Shopify Admin para atribución de afiliados.

## Entradas

- Conversiones en Prisma
- Eventos de facturación en Prisma
- Configuración de instalación en Prisma

## Salidas

- Métricas resumidas
- Tabla de conversiones recientes
- Resumen de principales afiliados

## No objetivos

- Pagos manuales
- Edición masiva de afiliados
